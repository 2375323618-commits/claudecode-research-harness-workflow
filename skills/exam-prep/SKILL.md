# Skill: 考试复习

> 针对经济计量/金融相关课程，生成概念梳理、知识图谱、练习题及答案解析。

## 输入

- **课程/科目**（必填）— 如"计量经济学""金融学""中级微观"
- **可选参数**：
  - 复习形式（概念梳理 / 知识图谱 / 练习题 / 综合）
  - 教材参考（如有）
  - 重点章节/主题
  - 题目数量
  - 题型（选择题/简答题/计算题/论述题）
  - 难度（基础/中级/高级）

## 输出

视复习形式而定：

### 概念梳理模式
- 按章节梳理核心概念
- 每个概念：定义 + 关键公式 + 直觉解释 + 易错点
- 关联概念之间的逻辑关系

### 知识图谱模式
- 可视化知识结构图（文本描述或 mermaid 图表）
- 概念之间的层级/依赖关系

### 练习题模式
- 题目 + 答案 + 解析
- 标注每个题考察的知识点
- 典型错误提示

## 使用方式

```
小马: "帮我梳理一下计量经济学第三章（多元回归）的重点概念"
我: 输出结构化概念梳理

小马: "出10道时间序列分析的练习题，有计算有简答"
我: 输出练习题 + 答案 + 解析

小马: "画一个面板数据模型的知识图谱"
我: 输出知识结构（mermaid图表）
```
