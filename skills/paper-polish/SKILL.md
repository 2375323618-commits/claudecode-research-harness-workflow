# Skill: 论文润色

> 对中英文学术论文段落进行润色，保持学术风格，附修改理由说明。

## 输入

- 待润色的论文段落
- 可选参数：语言（中文/英文）
- 可选参数：领域（经济学/金融学/管理学/其他）
- 可选参数：润色重点（语法/逻辑/风格/学术规范）
- 可选参数：期刊/会议要求（影响风格）

## 输出

润色结果，包含：
1. **润色后版本** — 直接可用的段落
2. **修改说明** — 逐处修改及理由（语法修正、用词优化、句式调整、逻辑梳理）
3. **整体评价** — 语言质量总评、可改进的方向

## 基本原则

- **保持原意** — 不改作者的核心观点和分析逻辑
- **学术规范** — 遵循学术写作惯例（被动语态、正式用词、避免口语化）
- **中文润色**：优化句式流畅度、术语统一、逻辑连接词
- **英文润色**：语法修正、用词精准、句式多样化
- **保留数据/公式/引用** — 不修改数字、方程、文献引用

## 使用方式

直接粘贴文字即可。长度不限，但如果超过 500 字我会分段处理。

## 示例

```
小马: "帮我润色这段中文论文：..."
我: 输出润色版 + 修改说明

小马: "这段英文帮我润色一下，投经济研究：..."
我: 输出润色版 + 修改说明
```
