# Skill: 任务执行流程

> 小马在 OpenClaw 下达任务指令后的标准化执行流程。
> 核心原则：**理解 → 规划 → 执行 → 交付**，每次任务走完整闭环。

---

## 1. 接收与理解

小马下达任务时，我需要立即明确：

| 需要明确的内容 | 问自己的问题 |
|---|---|
| **目标** | 小马想要什么结果？一个报告、一段代码、一张图、还是一段润色？ |
| **输入** | 数据在哪里？文件路径？还是直接贴文字？ |
| **约束** | 用什么工具（Python/Stata/Claude Code）？有什么特殊要求？ |
| **交付形式** | Markdown 报告？代码脚本？保存到哪个目录？ |

### 如果不明确 → 立刻反问

不要猜。一个清晰的问题比三次返工好。

## 2. 规划

确定任务类型后，选择合适的执行路径：

```
                ┌──────────────────┐
                │  任务类型判断     │
                └────────┬─────────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    ┌──────────┐  ┌──────────┐  ┌──────────┐
    │ 轻量任务  │  │ 常规任务  │  │ 复杂任务  │
    │          │  │          │  │          │
    │ exec 直跑 │  │ 调Claude │  │ 出Plan→  │
    │ Python/  │  │ Code CLI │  │ 小马确认→ │
    │ Stata    │  │ -p模式   │  │ 子代理   │
    └──────────┘  └──────────┘  └──────────┘
```

### 路径 A：轻量任务（我直接跑）
- 数据清洗、简单统计、画图、文档润色
- 方法：直接 `exec` 跑 Python / 或我直接输出文字

### 路径 B：常规任务（调 Claude Code CLI）
- 需要写代码跑模型、做复杂分析
- 方法：`claude -p "详细指令" --dangerously-skip-permissions`
- 我在提示里把任务拆清楚，Claude Code 执行

### 路径 C：复杂任务（Plan → 小马确认 → 子代理并行）
- 多步骤、多个独立数据源、需要不同工具
- 方法：出计划 → 小马确认 → 用 `subagent-dispatch` 拆解 → `sessions_spawn` 并行执行
- 参考 `agents/` 目录中的预定义代理角色

## 3. 执行

执行时的标准动作：

- ✅ **先看一眼代码/指令**再跑（特别是涉及文件操作的）
- ✅ **错误处理** — 出错先自己排查，3 次搞不定再问小马
- ✅ **进度汇报** — 耗时长的任务中间给一句状态
- ✅ **安全第一** — 不删文件、不改系统配置

### 顺序编排模式（第9章 模式①）

多步骤任务按以下顺序编排：

```
Step 1: 数据获取 → 搜索/读取数据
Step 2: 数据清洗 → 质量检查+清洗
Step 3: 数据分析 → 统计/建模
Step 4: 可视化 → 出图
Step 5: 结果解读 → 文字报告
Step 6: 迭代精修 → 检查质量+改进
```

每个步骤的**输入必须明确来自上一步的输出**，输出必须**标准化**以便下一步接收。
步骤之间允许跳过（如不需要画图就从 Step 3 直接到 Step 5）。

### 反馈与迭代

执行中可能遇到需要回头的情况：
- 数据问题 → 回到 Step 1/2 修复
- 模型问题 → 回到 Step 3 调整
- 结果不清晰 → 回到 Step 5 优化表述

返工不超过 3 次，3 次后通知小马介入。

## 4. 交付

交付时输出格式：

```
[结果/图表/代码在这里]

【简要说明】
- 做了什么
- 关键发现/结论（如果有）
- 文件保存位置（如果有）
```

### 如果结果不理想
直接说"这个结果不太对劲，可能是因为……"，给出判断和建议，不要硬交一个烂结果。

## 5. 后续

- 小马说"改一下xxx" → 迭代执行
- 小马说"行了" → 记录到 memory/
- 如果发现这个任务经常出现 → 考虑迭代完善对应的 Skill

| 数据文件概览 | A | Step 2 | 直接跑 pandas 脚本 |

| 面板数据 | C | Step 1→2→3→5 | 出 plan，子代理并行 |
| 论文润色 | A | — | 直接输出润色稿 |

| 出练习题 | A | — | 直接输出 |

| 画图 | A | Step 4 | 直接跑 matplotlib/seaborn |
| 政策分析 | A | Step 1→5 | web_search + 整理输出 |
