# Skill: 文献检索与综述

> 给定一个研究主题，系统化地搜索、筛选、提炼和整理文献，输出结构化综述笔记。

## 输入

- **研究主题**（必填）— 如"数字经济对全要素生产率的影响"
- **可选参数**：检索深度（快速概览/详细综述）
- **可选参数**：文献语言（中文/英文/不限）
- **可选参数**：时间范围（如近5年）
- **可选参数**：侧重方向（理论/实证/方法）

## 输出

结构化文献笔记（Markdown），包含：

1. **检索策略** — 使用的关键词、数据库/搜索引擎
2. **文献概览** — 该主题的研究热度、主要研究脉络
3. **核心文献**（每篇包含）：
   - 标题、作者、年份、期刊
   - 研究问题与方法
   - 核心发现或结论
   - 关键数据/变量（若有）
   - 🔗 链接
4. **研究脉络** — 按时间线或主题梳理发展脉络
5. **争议与未决问题** — 现有研究中的分歧和空白
6. **对本研究的启示** — 方法论参考、可拓展方向

## 工作流

1. `web_search` 搜索文献 → 获取标题、摘要、来源
2. 对相关度高的文献 `web_fetch` 获取详情
3. 提炼、归类、组织成综述笔记
4. 输出结构化 Markdown 到 `literature/` 目录
5. 迭代精修 → 自我检查文献完备性 → 补充遗漏方向

### 领域专业编排（第9章 模式⑤）

文献综述的标准化多步编排：

```
Step 1: 确定检索策略 → 关键词组合 + 数据库选择
Step 2: 初筛 → 搜索标题+摘要，剔除不相关
Step 3: 精读 → 对高相关文献获取全文摘要
Step 4: 归类 → 按研究主题/方法/发现分类
Step 5: 梳理脉络 → 识别发展路径和转折点
Step 6: 识别空白 → 争议点和研究缺口
Step 7: 输出综述 → 结构化 Markdown
Step 8: 迭代精修 → 检查遗漏 → 补充
```

## 示例

```
小马: "帮我找一下数字化转型对企业绩效影响的文献"
我: 运行 Skill → 输出结构化综述笔记 → 保存到 literature/
```
