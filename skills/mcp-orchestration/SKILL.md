# Skill: MCP 协调

> 管理 Claude Code 与外部工具/数据源的连接、协调多个 MCP 服务的任务编排。
> 对应第9章 设计模式②：多 MCP 协调。
> 当前暂未启用 MCP，此 Skill 作为预留框架，需要时直接使用。

---

## 1. MCP 是什么

MCP（Model Context Protocol）是 Claude Code 连接外部工具的协议。通过 MCP，Claude Code 可以：
- 读取数据库
- 调用 API
- 访问文件系统
- 执行外部命令
- 接入其他数据源

## 2. 适用场景（等需要时启用）

- 需要直接查询数据库获取数据
- 需要实时 API 获取金融行情
- 需要连接 Wind/东方财富等金融终端
- 需要自动化工作流（如定时跑模型）
- 需要跨工具协作（如 Claude Code + 本地 R 环境）

## 3. MCP 服务类型

| 类型 | 示例 | 何时使用 |
|---|---|---|
| **数据库 MCP** | MySQL, PostgreSQL, SQLite | 需要直接查数据库时 |
| **API MCP** | Wind API, 东方财富, FRED | 需要实时/定时取数据时 |
| **文件系统 MCP** | 本地文件读写 | 数据在本地需要 AI 操作时 |
| **自定义 MCP** | 自己写的脚本/服务 | 特殊需求 |

## 4. 多 MCP 协调模式（设计模式②）

当同时使用多个 MCP 服务时，按以下顺序编排：

```
Step 1: 任务分析 → 确定需要哪些外部数据/工具
Step 2: 连接 MCP → 按需启动对应 MCP 服务
Step 3: 数据获取 → 通过 MCP 获取数据
Step 4: 数据处理 → 整合多来源数据
Step 5: 分析/建模 → 在 Claude Code 中完成
Step 6: 结果输出 → 保存到文件
```

### 多 MCP 冲突处理

- **数据冲突**：两个 MCP 返回的数据不一致时 → 标注来源差异，由小马判断
- **连接失败**：一个 MCP 断开不影响其他 → 自动重试 2 次，不行通知小马
- **权限冲突**：涉及敏感数据时 → 现场反馈小马授权

## 6. 启用方式

当需要 MCP 时，我会：
1. 确认具体需求（什么数据源、什么格式）
2. 配置对应的 MCP server（JSON 配置文件）
3. 在 `claude -p` 调用中指定 `--mcp-config`
4. 验证连接是否正常
5. 开始数据获取和处理
