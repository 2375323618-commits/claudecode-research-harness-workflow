# Skill: 数据可视化

> 根据数据和分析目标，自动生成专业统计图表。

## 输入

- **数据**（文件路径或直接提供数据框描述）
- **图表类型**（可选，如不指定我会自动推荐）：
  - 折线图（趋势分析）
  - 柱状图/条形图（对比）
  - 散点图（相关关系）
  - 箱线图（分布对比）
  - 热力图（相关性矩阵）
  - 饼图/环形图（构成比）
  - 密度图/直方图（分布）
  - 组合图
- **X轴 / Y轴 变量**
- **分组变量**（可选）
- **可选参数**：
  - 标题、轴标签
  - 颜色主题
  - 保存格式（PNG, PDF, SVG）
  - 图表尺寸

## 输出

1. **图表**（保存到 figures/ 目录）
2. **说明** — 图表解读、关键数据标注

## 设计原则

- 经济学图表风格：干净、信息密度高、颜色克制
- 默认配置：ggplot 风格、Times New Roman / SimSun 字体
- 中英文图表自动适配标签语言
- 配合论文排版需求（宽/单栏适配）

## 使用方式

```
小马: "画一个2020-2025年GDP增长趋势图，数据在 data/gdp.csv"
我: 生成图表 + 保存 + 解读

小马: "把回归结果的系数画成森林图"
我: 生成图表 + 保存 + 解读
```
