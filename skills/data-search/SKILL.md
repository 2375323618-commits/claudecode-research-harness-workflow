# Skill: 数据搜索

> 根据小马的研究需求，在互联网上搜索真实的经济金融数据源和数据集。

## 原则

- **只用真实数据** — 不虚构、不模拟、不编造数据
- **优先官方来源** — 国家统计局、央行、Wind、CEIC、IFS、FRED、世界银行等
- **注明来源** — 每个数据源附链接和说明

## 输入

- **研究主题**（必填）— 如"各省GDP""CPI""上市公司财务数据"
- **可选参数**：
  - 地区（中国/全球/特定国家）
  - 时间范围（2020-2025）
  - 频率（年度/季度/月度/日度）
  - 数据类型（宏观/微观/面板/时间序列）

## 输出

数据源清单（Markdown），每条包含：
- 数据名称与描述
- 来源机构
- 覆盖范围（地区/时间/频率）
- 数据格式（CSV/Excel/API/网页）
- 🔗 链接 / 获取方式
- 获取难度（免费直下 / 注册下载 / 付费）
- 推荐优先级（⭐⭐⭐ 最推荐 / ⭐⭐ 可选 / ⭐ 备选）

## 常用数据源（供快速参考）

### 中国经济数据
| 来源 | 内容 | 链接 |
|---|---|---|
| 国家统计局 | 宏观月度/年度数据 | data.stats.gov.cn |
| 中国人民银行 | 金融统计数据 | pbc.gov.cn |
| 财政部 | 财政收支数据 | mof.gov.cn |
| 万得 Wind | 全领域金融数据（付费） | wind.com.cn |
| CEIC | 中国经济数据库（付费） | ceicdata.com |
| CSMAR | 上市公司数据（付费） | csmar.com |

### 全球经济数据
| 来源 | 内容 | 链接 |
|---|---|---|
| IMF IFS | 国际金融统计 | imf.org |
| World Bank | 世界发展指标 | data.worldbank.org |
| FRED | 美联储经济数据 | fred.stlouisfed.org |
| UN Comtrade | 国际贸易数据 | comtrade.un.org |
| OECD | 经合组织数据 | data.oecd.org |
| BIS | 国际清算银行数据 | bis.org |

### 其他公开数据集
- Kaggle 经济金融数据集
- GitHub 上的经济研究数据仓库
- 学术论文附录数据

## 工作流

1. `web_search` 搜索"主题 + 数据 + 数据集"
2. 对可信来源 `web_fetch` 核实可用性和格式
3. 整理成结构化数据源清单
4. 标注获取难度和推荐优先级
5. 如果小马确认要某个数据源，进一步获取

## 示例

```
小马: "帮我找中国各省近5年的GDP数据"
我: 运行 Skill → 输出数据源清单 → 推荐最优选择
```
