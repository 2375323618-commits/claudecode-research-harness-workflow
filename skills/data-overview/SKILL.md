# Skill: 数据概览

> 快速了解一个新数据集的全面情况。输入数据文件路径，输出结构化数据报告。

## 输入

- 数据文件路径（支持 CSV, Excel, Stata .dta, Parquet）
- 可选参数：目标变量名、是否需要可视化
- 可选参数：检查重点（缺失值、异常值、分布、相关性等）

## 输出

一份 Markdown 报告，包含：

1. **数据基本信息** — 行数、列数、每列类型
2. **缺失值分析** — 每列缺失比例、缺失模式
3. **描述性统计** — 数值列的均值、中位数、标准差、分位数、最大最小值
4. **分布可视化** — 数值列的直方图、类别列的频数条形图（保存到 figures/）
5. **异常值检测** — IQR 方法标记异常值数量及比例
6. **相关性矩阵** — 数值列之间的相关系数（热力图，保存到 figures/）
7. **初步结论** — 数据质量评估、值得注意的模式、下一步建议

## 使用方式

```python
# 调用示例（我会自动执行）
python scripts/data_overview.py --input data/yourfile.csv --output figures/
```

## 依赖

- pandas, numpy, matplotlib, seaborn

## 示例

```
小马: "看看 data/trade_data.csv 的数据情况"
我: 运行 Skill → 输出完整数据报告
```
