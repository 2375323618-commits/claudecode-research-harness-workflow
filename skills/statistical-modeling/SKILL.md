# Skill: 统计建模

> 根据研究问题和数据类型，选择合适的统计模型、运行并解读结果。

## 输入

- **数据文件路径**（CSV, Excel, .dta）
- **模型类型**（可选）：
  - 线性回归（OLS）
  - 时间序列（ARIMA, VAR, GARCH）
  - 面板数据（固定效应/随机效应）
  - Logit/Probit
  - 工具变量（IV/2SLS）
  - 其他（请说明）
- **因变量（Y）**
- **自变量（X）**
- **可选参数**：
  - 固定效应/聚类标准误设定
  - 滞后阶数
  - 控制变量列表
  - 稳健性检验要求

## 输出

1. **模型设定说明** — 选择的模型及理由
2. **回归结果表** — 系数、标准误、显著性、R² 等
3. **诊断检验**：
   - OLS：异方差检验、多重共线性（VIF）、正态性检验
   - 时间序列：单位根检验、残差自相关检验
   - 面板：Hausman 检验、F检验（混合/固定/随机）
4. **结果解读** — 核心变量的经济含义与统计显著性
5. **图表**（如需）— 残差图、预测vs实际图、系数图等（保存到 figures/）

## 工作流

- 简单模型 → 直接 Python (statsmodels)
- 复杂面板/IV/高级模型 → 调用 Claude Code 或 Stata

### 领域专业编排（第9章 模式⑤）

统计建模的标准多步编排：

```
Step 1: 数据准备 → 检查数据质量、变量类型、缺失处理
Step 2: 探索性分析 → 描述性统计、相关矩阵、可视化探查
Step 3: 模型选择 → 根据数据类型和研究问题选模型
Step 4: 模型估计 → 运行模型
Step 5: 诊断检验 → 检查模型假设是否满足
     ├─ 通过 → 进入 Step 6
     └─ 不通过 → 返回 Step 3 调整模型设定
Step 6: 稳健性检验 → 换变量定义/换样本/换方法
Step 7: 结果解读 → 经济含义 + 统计显著性
Step 8: 迭代精修 → 质量检查 → 改进
```

每个步骤的输出作为下一步的输入，步骤之间用文件传递中间结果。

## 示例

```
小马: "帮我跑一个面板固定效应模型，数据在 data/panel_data.csv，Y是gdp，X是edu spend"

```
