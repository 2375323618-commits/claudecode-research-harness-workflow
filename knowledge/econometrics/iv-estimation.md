# 工具变量法 IV/2SLS

> 当解释变量与误差项相关（内生性）时，OLS不一致。工具变量法（IV）是标准解决办法。

---

## 1. 什么时候需要IV

### 内生性来源
| 来源 | 含义 | 例子 |
|---|---|---|
| 遗漏变量偏误 | 遗漏的同时影响Y和X的变量 | 能力影响收入和受教育年限 |
| 反向因果 | Y影响X | GDP高→教育投入多，教育也影响GDP |
| 测量误差 | X测量不准 | 自报收入有噪音 |

### 内生性检测
```python
# Hausman检验：比较OLS和IV是否显著不同
# 显著差异 → 存在内生性
```

## 2. IV的条件

一个有效工具变量 Z 必须满足两个条件：

| 条件 | 含义 | 检验方式 |
|---|---|---|
| **相关性** | Cov(Z, X) ≠ 0 | 第一阶段F统计量 > 10（经验法则） |
| **外生性** | Cov(Z, ε) = 0 | 无法直接检验，需要理论论证 |

## 3. 两阶段最小二乘法（2SLS）

```
Stage 1: X = γZ + ν          → 得到拟合值 X_hat
Stage 2: Y = βX_hat + ε      → 用拟合值回归
```

Python:
```python
from linearmodels.iv import IV2SLS

model = IV2SLS.from_formula(
    'Y ~ 1 + Controls + [X ~ Z]',
    data=df
)
results = model.fit(cov_type='robust')
print(results)
```

Stata:
```stata
ivregress 2sls Y Controls (X = Z), robust
ivregress 2sls Y Controls (X = Z Z2), robust  // 多个IV
```

## 4. IV诊断检验

| 检验 | 什么用 | 判断标准 |
|---|---|---|
| **第一阶段F统计量** | 工具相关性 | F > 10 为强工具变量 |
| **弱工具变量检验** | 工具是否足够强 | Cragg-Donald Wald F > Stock-Yogo临界值 |
| **过度识别检验**（Sargan/Hansen J） | 工具外生性（IV数量>内生变量时） | p > 0.1 接受H0（工具外生） |
| **内生性检验**（Hausman/DWH） | 是否需要IV | p < 0.05 → 需要IV |

## 5. 弱工具变量问题

弱工具变量（F < 10）导致：
- IV估计量有偏（偏向OLS）
- 标准误很大
- 推断不可靠

### 处理方式
- 找更强的工具变量（理论上更相关）
- 使用有限信息最大似然（LIML）
- 用 Anderson-Rubin 置信区间（对弱工具变量稳健）

## 6. 模型诊断流程

```
IV回归结果
    │
    ▼
[第一阶段F统计量]
    │
    ├─ F > 10 → 工具变量强
    │   └─ [过度识别检验]（如有）
    │       ├─ p > 0.1 → 工具外生，结果可信
    │       └─ p < 0.1 → 部分工具可能不满足外生性
    │
    └─ F < 10 → 弱工具变量
        └─ 提示小马：结果可能不可靠
```

## 7. 常见工具变量类型

| 场景 | 常用IV | 理论逻辑 |
|---|---|---|
| 教育对收入 | 义务教育政策/改革 | 政策影响教育但不直接影响收入 |
| 制度对增长 | 殖民者死亡率 | 历史因素影响制度但不直接影响增长 |
| 贸易对增长 | 关税/距离/语言 | 地理/历史因素影响贸易但不直接影响增长 |
| 移民对工资 | 历史移民分布 | 历史分布影响当前但不直接影响当前工资 |
| 信贷对消费 | 房贷政策 | 政策影响贷款但不直接影响消费 |
