# Skill: AI 工具调度

> 根据任务类型、复杂度、安全等级，自动选择最合适的 AI 工具/软件来执行。
> 小马发号施令 → 我判断用哪个工具 → 执行 → 交付结果。

---

## 1. 工具概览

| 工具 | 类型 | 适用场景 | 调度方式 |
|---|---|---|---|
| **OpenClaw（我）** | 调度中枢 + 轻量执行 | 规划、理解需求、文字处理、web_search、简单 Python/Stata | 直接对话 |
| **Claude Code** | 主力 coding agent | 写代码、跑模型、数据分析、文件操作、复杂任务 | `claude -p "..." --dangerously-skip-permissions` |
| **Cursor** | AI 编辑器 | 需要手动调试代码、交互式写代码、看代码效果 | 告知小马打开 Cursor |
| **Opencode** | 替代 coding agent | Claude Code 不可用时的备选 | `opencode -p "..."` |
| **Claude Desktop** | 对话式 AI | 需要深度对话、长上下文讨论 | 告知小马打开 |
| **子代理** | 并行独立会话 | 复杂任务的子任务拆解 | `sessions_spawn` |

## 2. 任务-工具映射矩阵

| 任务类型 | 默认工具 | 备选 | 说明 |
|---|---|---|---|

| **数据可视化** | OpenClaw（exec python） | Claude Code | 简单的图直接画 |
| **论文润色** | OpenClaw（直接输出） | — | 文字工作，不需要工具 |
| **文献综述** | OpenClaw（web_search） | — | 网络搜索即可 |
| **经济政策分析** | OpenClaw（web_search） | — | 网络搜索即可 |

## 3. 上下文感知选择（第9章 模式④）

同一类任务在不同上下文中可能走不同路径。判断标准：

### 上下文维度

| 维度 | 影响 | 示例 |
|---|---|---|
| **数据规模** | 小数据直跑，大数据调 Claude Code | <1000行直跑，>10000行调 claude |
| **精度要求** | 探索性分析放宽，论文级严格 | 论文级结果必须加诊断检验 |
| **时间压力** | 紧迫时走最快路径 | 先给快速结果再迭代优化 |
| **安全等级** | 公开数据直跑，隐私数据先问 | 研究数据要先问 |
| **工具可用性** | 首选工具不可用自动降级 | Claude Code 挂 → Opencode |
| **任务熟悉度** | 首次任务多确认，重复任务快速跑 | 新类型先出 plan，旧类型直接执行 |

### 决策树（增强版）

```
任务来了
  │
  ├─ 纯文字/查资料/简单计算
  │   ├─ 且数据<1000行 → OpenClaw（直接干）
  │   └─ 且数据>10000行 → 调 Claude Code 处理
  │
  ├─ 需要写代码/处理文件/跑模型
  │   ├─ 代码简单且确定性强 → OpenClaw exec python
  │   ├─ 代码复杂或不确定 → Claude Code claude -p
  │   └─ 多步骤需编排 → 按顺序编排模式执行
  │
  ├─ 需要人机交互调试代码 → 通知小马打开 Cursor
  │
  └─ 需要深度讨论长文档 → 通知小马打开 Claude Desktop

工具不可用时的降级路径：
Claude Code 挂了 → Opencode
OpenClaw 不能直接跑的 → Claude Code
```

## 4. 安全分级

| 级别 | 数据范围 | 处理方式 |
|---|---|---|
| 🔵 **常规** | 公开数据、通用知识、课程内容 | `--dangerously-skip-permissions` 直接跑 |
| 🟡 **敏感** | 小马的研究数据、未发表论文、作业 | 先问小马，不加 `--dangerously-skip-permissions` |
| 🔴 **机密** | 个人凭证、系统配置、第三方账户 | 先问小马，手动操作 |

### 隐私数据的判断标准
- ✅ 小马的研究数据（CSV、Excel、.dta）
- ✅ 未发表的论文草稿
- ✅ 个人凭证（API key、密码）
- ✅ 系统配置变更
- ❌ 公开数据集
- ❌ 课程习题
- ❌ 已发表的论文

## 5. 使用示例

```
小马: "帮我跑一个回归模型，数据在 data/reg.csv"
我: 判断 → 数据<10000行 + 常规回归 + 公开数据
    → OpenClaw直接跑 statsmodels
    → 交付结果 + 诊断检验

小马: "帮我做一篇完整的文献综述，关于绿色金融"
我: 判断 → 文字任务 + 多步骤 → web_search + 整理输出
    → 交付结构化综述

小马: "分析这个大面板数据，100万行"
我: 判断 → 数据量大 → 调 Claude Code
    → claude -p "分析 data/panel.csv" --dangerously-skip-permissions
    → 交付结果
```

## 6. 执行原则

- **透明告知** — 每次调度都告诉小马"我用什么工具做什么"
- **自动切换** — 一个工具不行自动换下一个，不卡住
- **安全第一** — 涉及隐私数据/系统修改，先问小马
