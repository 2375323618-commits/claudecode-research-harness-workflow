# Skill: 经济政策/案例分析

> 对经济政策或经济事件进行系统分析，输出结构化案例研究文本。

## 输入

- **分析对象**（必填）— 政策名称/事件/案例
- **可选参数**：
  - 分析框架（供求分析 / 成本收益 / 制度分析 / 政策评估等）
  - 国家/地区
  - 时间范围
  - 侧重角度（理论/实证/政策建议）
  - 字数要求

## 输出

结构化分析报告（Markdown），包含：

1. **背景概述** — 政策/事件的来龙去脉、时间线
2. **核心内容** — 政策具体条款、事件经过
3. **理论框架** — 适用的经济学理论（外部性、信息不对称、博弈论等）
4. **影响分析**：
   - 经济影响（GDP、就业、物价、贸易等）
   - 行业影响（受益人/受损方）
   - 分配效应（公平性分析）
5. **国际比较** — 类似政策/事件的国际经验
6. **争议与评价** — 学术界/业界的观点分歧
7. **结论与启示** — 政策建议、未来展望

## 工作流

1. `web_search` 收集资料
2. 调用相关网页获取详情
3. 组织分析框架
4. 输出结构化报告

## 示例

```
小马: "分析一下最近的MLF利率调整对经济的影响"
我: 搜索资料 → 输出结构化分析报告
```
