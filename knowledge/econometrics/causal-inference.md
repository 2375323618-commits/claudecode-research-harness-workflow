# 因果推断

> 因果推断是应用经济学的核心。相关 ≠ 因果，识别因果需要研究设计。

---

## 1. 因果识别框架

```
你想知道 X 对 Y 的因果效应
    │
    ▼
X 是随机分配的？→ YES → 直接比较均值（RCT）
    │
    NO
    │
    ▼
有什么自然实验/政策冲击？→ YES → DID / RDD / IV
    │
    NO
    │
    ▼
面板数据可用？→ YES → FE / 一阶差分
    │
    NO
    │
    ▼
匹配/控制变量足够？→ 倾向得分匹配 / 合成控制
```

## 2. 常用方法总览

| 方法 | 核心思想 | 关键假设 | 适用场景 |
|---|---|---|---|
| **RCT** | 随机分组 | 随机性 + 无污染 | 实验室/实地实验 |
| **DID** | 处理组 vs 控制组，政策前后 | 平行趋势 | 政策评估 |
| **RDD** | 断点附近近似随机 | 连续性假设 | 阈值政策 |
| **IV/2SLS** | 利用外生变异 | 工具外生 + 相关 | 内生性问题 |
| **FE** | 控制个体不随时间变化的因素 | 严格外生性 | 面板数据 |
| **PSM** | 匹配可观测特征 | 可忽略性 | 观察数据 |
| **合成控制** | 构造反事实 | 拟合好 + 无干扰 | 单个处理单元 |

## 3. 双重差分（DID）

### 标准DID设定
```
Y_it = α + β(Treat_i × Post_t) + γTreat_i + δPost_t + ε_it
```

### 关键假设
1. **平行趋势**：处理组和控制组在政策前有相同的趋势
2. **无预期**：处理组没有提前调整行为
3. **无干扰/溢出**：控制组不受政策影响

### 平行趋势检验
```python
# 事件研究法（Event Study）
# 估计政策前各期处理组与控制组的差异
import statsmodels.api as sm

# 相对时间虚拟变量 × 处理组交互项
df['rel_time'] = df['year'] - policy_year
df['treat_time'] = df['treated'] * df['rel_time']

# 回归（去掉政策前一期作为基准）
mod = sm.OLS.from_formula(
    'Y ~ C(rel_time, Treatment("pre_1"))*treated + C(id) + C(year)',
    data=df
)
```

### 平行趋势图示
```
Y轴：Y的均值
   │      处理组 ──── 控制组 ────
   │        \    /
   │         \  /  ← 政策后分化
   │          \/
   │          /\
   │   ___/\_/  \
   │  /    \     \
   │ /      \     \
   └─────────────────────────────── X轴：时间
            政策时点
```

### 多期DID & 交叠处理
- **Staggered DID**：不同个体在不同时点受处理
- **问题**：处理效应异质性时，标准TWFE估计量可能出偏
- **替代方案**：Callaway & Sant'Anna / Sun & Abraham / CSDID

### Stata DID
```stata
* 标准DID
reg Y i.treat##i.post, robust

* 交互固定效应（多期）
reghdfe Y treat_post, absorb(id year) cluster(id)

* 事件研究
gen rel_time = year - policy_year
forvalues t = -5/5 {
    gen T_`t' = (rel_time == `t')
}
reghdfe Y T_*, absorb(id year) cluster(id)
```

## 4. 断点回归（RDD）

### 精确RDD
```
Y_i = α + βTreat_i + f(Assignment_i) + ε_i
其中 Treat_i = 1(Assignment_i ≥ c)
```

### 关键假设
- **连续性假设**：潜在结果在断点c处连续
- **操纵检验**：个体不能精确操纵分配变量

### RDD检验
1. **密度检验**（McCrary检验）：分配变量在断点附近不能有跳跃
2. **协变量平衡检验**：控制变量在断点处不能有显著差异
3. **带宽敏感性**：不同带宽下结果是否稳健
4. **伪断点检验**：在其他位置是否存在伪跳跃

## 5. 合成控制法（SCM）

### 适用场景
- 一个省份/城市/国家受政策影响
- 其他未受政策影响的单元作为"对照池"
- 构造一个"合成控制组"作为反事实

### 关键要素
- **处理前拟合**：处理前合成组必须紧密匹配处理组
- **安慰剂检验**：随机分配处理，看真实效应是否极端
- **处理组/对照组数量**：控制组2-20个，处理组1个最优

## 6. 检验清单

做完因果识别后，必须检查：

- [ ] 结果是否对模型设定敏感？
- [ ] 平行趋势是否满足（DID）？
- [ ] 断点附近无操纵（RDD）？
- [ ] 工具变量是否足够强（F>10）？
- [ ] 结果是否受异常值驱动？
- [ ] 不同带宽/窗宽是否稳健？
- [ ] 安慰剂检验是否通过？
- [ ] 结果有无经济意义？
